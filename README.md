# SLIMP3 Player for Home Assistant

Home Assistant app that acts as the server for a Slim Devices SLIMP3, streaming
from DLNA/UPnP media servers such as Plex.

This application is written through the harness [Krystalize.AI](https://krystalize.ai/) - get your Mac M series private local LLM with memory for managing all of your development processes or as a local Chief of Staff.

Add this repository in Home Assistant: **Settings > Apps > App store > menu >
Repositories**, then paste `https://github.com/DaveMath/SLIMP3-for-HA`.
